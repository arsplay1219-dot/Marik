Выбери передачу слева или нажми ＋, чтобы добавить новую.

Это временный просмотр только в этом браузере — после перезагрузки страницы он пропадёт. Чтобы видео работало у всех и в OBS, загрузи mp4-файл в свой репозиторий на GitHub (например, в папку videos) и впиши сюда его адрес вида videos/имя.mp4.

Добавь эту ссылку как Browser Source в OBS Studio — канал сам будет показывать передачу по расписанию (по времени начала) в цикле, без входа через Google (Google блокирует вход внутри встроенных браузеров вроде OBS).

Сохранение в браузере видно только тебе на этом устройстве и не видно OBS. Чтобы плейлист был одинаковым у всех зрителей и в OBS — скопируй код ниже, замени им блок DEFAULT_SHOWS в файле index.html и загрузи файл на GitHub заново.
